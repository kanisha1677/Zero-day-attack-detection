## Zero-Day Network Attack Detection using AI & Machine Learning

## Overview

Traditional Intrusion Detection Systems (IDS) rely on attack signatures and often fail to detect zero-day attacks.

Our proposed system combines:

* Isolation Forest
* Autoencoder
* Random Forest
* XGBoost
* Ensemble Voting
* SHAP Explainability

to detect unknown attacks by analyzing network traffic patterns.

## Features

* Zero-Day Attack Detection
* AI-based Anomaly Detection
* Attack Classification
* SHAP Explainability
* Real-Time Dashboard

## Workflow

Network Traffic → Feature Extraction → Isolation Forest/Autoencoder → Random Forest/XGBoost → SHAP → Alert Dashboard
